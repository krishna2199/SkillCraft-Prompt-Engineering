# SkillCraft Prompt Engineering Portfolio

This repository contains my work for the four Prompt Engineering tasks in the SkillCraft Technology brief. Each task folder includes the prompts, examples or model responses, and a short report on what I observed.

## Tasks

- **Task 1 — Writing Better Prompts:** three vague prompts rewritten with clearer instructions, followed by output comparisons.
- **Task 2 — Prompting for Creativity:** four prompt versions tested on a startup-idea task, with a comparison of tone, creativity and detail.
- **Task 3 — Prompting for Task Automation:** meeting notes converted into a consistent JSON task-tracker format, with examples and a reflection on prompt changes.
- **Task 4 — Simulating an Assistant:** a mock interview coach that follows a prompt sequence and adapts its next question to the conversation.

## How to explore the project

Start with the README inside each task folder. The `prompts` folders show how the instructions changed, while `results` contains the examples used in the comparisons. The reports describe the main observations and limitations.

## Tools

The saved model responses for Tasks 1–3 were generated with Ollama and `qwen2.5:3b`. Some files are saved outputs rather than freshly generated results, so refer to the individual task reports for details. The Task 4 assistant can be run locally with Python; its saved conversations are included for review.

The examples use fictional scenarios and should be treated as a small learning exercise, not as proof of general model accuracy. Review the prompts and outputs before reusing them.
